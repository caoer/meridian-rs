# comment-cleanup notes

Generated by the `comment-cleanup` workflow (`.claude/workflows/comment-cleanup.js`).

Each `<path>.md` mirrors a `.rs` file at the same repo-relative path and holds:

- **Key information sections** — comment substance the rewriter moved out of the
  code when it was too big for a minimal comment (`## <topic> (from <file>:<line>)`).
- **`## Review verdict: GO|NO-GO`** — the independent codex reviewer's verdict for
  that file's rewrite: mechanical code-invariance gate result
  (`tools/comment-audit/invariance.py`), info-preservation, and style.

A NO-GO records what is wrong; nothing is auto-reverted or iterated.
